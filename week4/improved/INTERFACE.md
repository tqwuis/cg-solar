# 명판 중심 관찰 인터페이스

`baseline`을 복사한 새 `improved`에서 구현했다. `baseline`, `Old`, 제공 모델 파일은 수정하지 않는다. 외부 라이브러리나 빌드 없이 HTTP 서버 또는 GitHub Pages에서 `index.html`을 실행한다.

## 조작

| 입력 | 원근 관찰 | 전면·측면 직교 |
| --- | --- | --- |
| 왼쪽 드래그 | 중심을 기준으로 좌우 회전 | 화면 평행 이동 |
| Shift + 드래그 / 오른쪽 드래그 | 화면 평행 이동 | 화면 평행 이동 |
| 휠 / +·− 버튼 | 중심까지의 거리 조절 | 직교 표시 범위 조절 |
| 좌우 방향키 | 좌우 회전 | 화면 좌우 이동 |
| WASD / 방향키 | WASD 이동 없음 | 화면 상하좌우 이동 |
| Space / 구조물 반투명 버튼 | 명판 외 구조물의 반투명 상태 토글 | 동일 |
| 명판·번호 표시 클릭 | 해당 명판 정면으로 접근하고 선택 | 원근 관찰로 전환해 해당 명판 정면으로 접근 |
| Home / 전체 보기 | 원근 전체 보기까지 부드럽게 이동 | 현재 직교뷰의 전체 범위까지 부드럽게 이동 |

baseline의 회전·평행 이동·거리 조절 입력을 유지하면서 회전 자유도만 yaw로 제한했다. 카메라의 높이는 target의 높이와 같고 `up=[0,1,0]`으로 고정한다. 상하 회전은 없으며 높이를 바꾸려면 Shift 드래그를 사용한다.

Old에서 사용하던 전면·측면 직교뷰의 WASD·드래그 이동, 확대·축소, 뷰별 상태 보존을 가져왔다. 직교뷰를 보는 동안 원근 카메라의 target·distance·yaw·FOV를 변경하지 않아 원근 관찰 버튼으로 이전 상태에 돌아갈 수 있다. 직교뷰에서 명판을 선택하는 것은 새로운 원근 관찰 대상을 지정하는 동작이다.

## 명판 선택과 가림 판정

- `d04-inspection-picking.js`에서 화면 좌표를 원근/직교 광선으로 바꾼다. 모델 명판의 위치·크기·yaw로 사각형 교차를 검사한다.
- 불투명 상태에서는 구조물의 AABB 교차로 가림을 검사한다. 구조물이 먼저 맞으면 뒤의 명판을 선택하지 않는다.
- 반투명 상태에서는 구조물 가림을 무시한다. 명판끼리 겹치면 가까운 명판이 선택된다. 화면 밖이나 카메라 뒤의 명판은 선택되지 않는다.
- 번호 표시는 화면에 보이는 명판의 선택 영역을 보조한다. 오른쪽 P1~P6 버튼은 항상 선택할 수 있다. 명판의 답은 UI에 따로 표시하지 않는다.
- 명판의 뒷면도 식별할 수 있다. 글자는 제공 모델처럼 한쪽 면에 유지하고, 클릭하면 정면으로 이동해 읽는다.
- 포인터가 5 CSS 픽셀 이상 움직이면 드래그로 처리하며, 이 경우 클릭 이동을 발생시키지 않는다.

선택 시 target을 명판 중심으로 옮기고 yaw를 명판 정면 법선 방향으로 맞춘다. 명판 너비·높이, FOV와 캔버스 비율로 접근 거리를 계산한다. 카메라를 명판 표면과 동일한 점에 두지 않고 글자를 읽을 수 있는 거리에 둔다.

접근은 약 0.85초 동안 진행한다. target·거리·yaw를 시작과 끝에서 천천히 움직이는 곡선으로 보간하고, yaw는 짧은 회전 방향을 선택한다. 이동 중에도 up은 고정되며 초록색 외곽선을 유지한다. 다른 명판을 누르면 현재 이동 중인 시점에서 새 목적지로 이어지고, 드래그·휠·방향키·Home·뷰 전환으로 직접 조작하면 자동 이동을 취소한다. 직교뷰에서 선택할 때도 현재 직교 카메라 위치에서 출발하며, 중심 평면의 표시 크기에 맞춘 FOV를 원근 관찰 FOV로 함께 보간한다.

전체 보기 버튼과 Home 키도 약 0.85초 동안 이동한다. 원근뷰는 target·거리·yaw·FOV를, 직교뷰는 target과 표시 범위를 보간한다. 직교뷰에서 전체 보기를 해도 저장된 원근 시점은 유지된다. 페이지를 처음 열 때는 바로 전체 모습을 표시한다.

오른쪽 목록에서 현재 가려졌거나 화면 밖인 명판을 선택하면 반투명을 켜고 현재 시점에서 원근 전체 보기까지 약 0.85초 동안 이동한다. 전체 모습을 약 0.18초 보여 준 뒤 약 0.85초의 명판 접근 애니메이션을 시작한다. 이미 반투명인 경우에는 켜진 상태를 유지하며, 전체 보기 이동·대기·명판 접근 어느 단계에서든 직접 조작하면 남은 이동을 취소한다. 현재 보이는 명판은 전체 보기를 거치지 않고 현재 시점에서 바로 접근한다.

## 반투명과 외곽선

제공된 건물·가구·설비·지면 등 모든 box를 반투명으로 그린다. 명판은 불투명하게 유지한다. 구조물은 거리순으로 알파 혼합하고 깊이 기록을 끈 뒤, 명판을 깊이 검사와 함께 그려 가려진 표지까지 드러나게 한다. 따라서 이 모드는 물리적으로 정확한 유리 투과보다 관찰을 위한 가림 해제에 목적이 있다. 구조물끼리 교차하는 부분의 투명 정렬은 근사이다.

선택된 명판의 바깥에 초록색 테두리를 별도로 그린다. 원본 명판의 내용·크기·위치는 바꾸지 않는다. 회전, 평행 이동, 휠, 키보드 이동, Home, 뷰 전환 시 선택과 테두리를 해제한다. 반투명 토글 자체는 카메라 이동이 아니므로 선택을 유지한다.

## 8개 관찰 지점과 UI

P1~P6은 명판·번호 표시 또는 오른쪽 목록으로 접근한다. 목록에는 화면 밖인지, 가려졌는지, 이동 중인지, 현재 관찰 중인지 표시하며, 보이지 않는 명판도 버튼을 눌러 자동으로 찾아갈 수 있다. O1/O2 카드는 해당 두 비교 대상을 포함하도록 전면/오른쪽 측면 직교 카메라를 맞춘다. 모델을 숨기거나 치수를 바꾸지 않는다.

## 검증

`tests/interaction.html`을 HTTP 서버에서 열면 실제 WebGL 뷰어를 포함한 브라우저 검증을 실행한다. 광선 선택, 불투명 가림, 반투명 토글, 앞뒤 명판 접근, 드래그/클릭 구분, 외곽선 픽셀, 선택 해제, 직교 상태 보존, WASD 이동, 알파·깊이 상태, 좁은 화면 레이아웃을 검사한다. 합성 포인터 검증에서는 pointer capture를 모사한다.

추가로 Headless Chrome의 실제 입력 경로로 Space → 구조물 뒤 명판 클릭 → 정면 접근 → 드래그 시 테두리 해제를 확인했다. 이 검증은 사용자 관찰 시간 측정이 아니다.
